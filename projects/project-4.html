分布式爬虫系统

项目简介

基于 Scrapy + Redis 的分布式爬虫系统，支持电商、新闻、社交等多类型站点的高并发数据采集。

技术栈

PythonScrapyRedisSeleniumRequestsMongoDB

核心功能

  • Redis 分布式调度，支持多节点横向扩展与任务去重
  • 集成代理池与验证码识别，高效应对反爬策略
  • 断点续爬与失败重试机制，保障采集任务的完整性
  • 数据清洗与结构化入库，日均采集量达百万级

我的职责

负责爬虫架构设计、核心爬虫开发与反爬对抗，保障采集稳定性与数据质量。

项目成果

单节点日采 50 万+ 数据，分布式扩展后达百万级；数据完整率 98% 以上，支撑下游数据应用。
